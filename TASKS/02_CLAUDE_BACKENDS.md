# Claude Code — Model/backend comparison and hybrid pipeline (track B)

You own extraction architecture and implementation; Codex separately owns independent gold and evaluator. Do not edit benchmark gold/metric code. Start by reading `AGENTS.md`, `docs/EVAL_PROTOCOL.md`, `baseline_v2/parser_v2.py`, `baseline_v2/README.md`, then inspect machine via `python --version`, `free -h`, `nvidia-smi` (if present), `df -h`; do not alter NVIDIA drivers.

Central research hypothesis: **native PDF text is fastest and most faithful on good digital financial tables, but fails on raster pages or complex table structures; conditional model-backed structure and OCR can increase coverage without compromising source fidelity.** Validate or reject this hypothesis using measured comparisons.

Priority:
1. **Frozen native adapter**: package existing v2 as one backend with `extract(pdf, page_index)->DocumentPrediction`. Preserve native exact text, source bounding boxes and an explicit capability/error status. Never quietly suppress its failure.
2. **Docling TableFormer ACCURATE**: use the official current `DocumentConverter`+`PdfPipelineOptions(do_table_structure=True)` path and test `do_cell_matching=True` against `False`. Save raw `DoclingDocument` JSON, recognized table grid/spans and Markdown, plus optional normalized common-schema mapping. Record model version, memory and total inference time. Try CPU if GPU unsuitable; do not spend the sprint debugging NVIDIA kernels.
3. **Genuine visual backend**: attempt **PaddleOCR-VL-1.6 full pipeline** including layout and recognizer (not just base 0.9B) on original and a rasterized sample. Use a separate virtual environment/optional dependency to avoid conflicting Paddle/Torch requirements. Official Python example: `from paddleocr import PaddleOCRVL; pipeline=PaddleOCRVL(); results=pipeline.predict(input=pdf_path); [r.save_to_json(...), r.save_to_markdown(...)]`. Inspect docs for model selection and hardware options. Record actual checkpoint and architecture. 6GB VRAM may be insufficient; never claim fit without successful measurement. If infeasible after one limited attempt, substitute Japanese OCR (PaddleOCR PP-StructureV3 or Tesseract `jpn`) and document the failed attempt/why.
4. **Adaptive routing**: simple, inspectable decision based on extractable glyph density, repeated numeric anchors, expected table area, layout detector output, and backend agreement. No learned confidence probability until calibrated. Return `needs_visual_review` on unresolved disagreements. Do not force image predictions to overwrite verified glyphs. Selective crop re-run is optional high-value optimization only after basic model execution works.
5. **Generalized tables**: common lossless intermediate with multiple tables/page; ordered rows; N data columns with role + period + unit; header cells with `rowspan`/`colspan`; cell bbox and source method. Keep financial hierarchy as optional semantic enrichment, not a mandatory precondition for a table to exist. Safely preserve percentages, decimals, plus and minus signs, Japanese footnotes and superscripts.
6. **Conservative validator**: check only recognizable arithmetic and transformations (gross+negative accumulated depreciation≈net; subtotal composition; delta=current−previous when columns are semantically identified); report anomalies but never auto-repair. Treat rounding allowances as explicit, named policy.
7. **Run full regression and export compelling evidence**: original + independent page if downloaded + raster, compare both pipelines and report concrete failure crops. Document if backend is skipped, unavailable, crashes, or requires more memory.

Deliverables: `findoclens/`, `adapters/`, `runs/`, optional `requirements-models.txt` and `venv` setup docs, unit/integration tests, adapter comparison summary. Avoid training or serving unless all preceding gates pass. Offer a working runnable command `python -m findoclens parse ... --backend auto --format json,md` or equivalent. Be explicit that full PaddleOCR-VL is optional and may be blocked on a laptop.

Done when: baseline preserved; at least one truly new backend has executed or its failure is recorded with logs; new parser handles exact Japanese numeric semantics and emits evidence; no invented success metrics; findings can be evaluated by Codex harness.
