# Delivery scope and preserved history

Implementation and V3 reference freeze: `9a6ebcb5c24ed80caaed59092ebb6f1608547016`. Core parser/adapters/evaluator and `baseline_v2/` remain unchanged during packaging. `START_HERE.md` is the evaluator entrypoint; `FINAL_REPORT.md` is the concise technical report. Older reports and the independent AI review are historical, with their original confidence statements preserved. The new V3 report supersedes earlier human-review status, not earlier measurements.

The repository retains all experiment history; `submission/GIT_HISTORY.txt` provides the pre-delivery commit index, and the archive build metadata identifies the delivery source commit. The ZIP is a compact selection: all source/test/environment/reference/report files, locked V3 and v1/v2 records, original assignment input, fin1 and post-fix cold predictions/measurements/raw records plus metadata, relevant review evidence, and a portable viewer using only the supplied original and its controls/synthetic pages. Repeated warm predictions, exploratory/aborted run directories, large duplicated images, caches, environments, model weights and Git internals are excluded. Warm measurements remain in run metadata. `PACKAGE_MANIFEST.json` enumerates exact files and omissions; stored reference/score/prediction bytes are unchanged.

ELECOM/Daiwabo PDFs and all rendered filing imagery are excluded because redistribution permission is unreviewed. Source URLs, original page numbers and hashes remain in `benchmark/manifest.jsonl`, `benchmark/sources/` and `docs/SOURCE_MANIFEST.md`. Source restoration is an explicit optional step. The supplied assignment page and its own evidence render are included for return to its reviewers, not as a blanket redistribution license.

Historical records can contain the original machine's absolute paths, interpreter locations and cache paths. They are inert provenance, retained unchanged so hash-pinned predictions and immutable baselines remain verifiable. New entrypoints use relative paths; no runtime dependency on that user's home directory is introduced. The package audit enumerates these strings separately from secrets. No detected credential formats or complete AI transcripts are included; the scan is not a proof that arbitrary secrets are impossible.
